The safe has a combination lock with four dials showing digits
from 0 to 9. In one move you may turn exactly one dial by one
step up or down. The dials are circular: after 9 comes 0, and
before 0 is 9. The current code A is entered, then on the next line
the target code B. Both are four-digit numbers with no leading
zeros. Find the minimum number of moves to reach the target
code from the current one. Example: from 1000 to 1009 - 1 move
(turn the last dial from 0 to 9).

У сейфа кодовый замок из четырёх дисков с цифрами от 0
до 9. За один ход можно повернуть один диск на одну
позицию вверх или вниз. Диски циклические: после 9 идёт 0,
перед 0 - 9. Вводится текущий код А, на следующей
строке - целевой В. Оба четырёхзначные, без ведущих
нулей. Найди минимальное количество ходов для получения
целевого кода из текущего. Пример: из 1000 в 1009 - 1 ход
(повернуть последний диск с 0 на 9).
